# Conditionals and Loops

## Conditionals with Booleans

- Use `boolalpha` if you want booleans to print true or false instead of 1 or 0

## For loops

- Use a for loop when you know how many times you want to execute the loop for
- Start with the `for` keyword then paraenthasis with 3 parts split by semicolons
  - 1. Initialize the index
    - `int i = 0;`
  - 2. Condition - Loop runs while condition is true
    - `i < 10;`
  - 3. What we are going to do with the index each time the loop runs
    - `i++`
  - `for (int i = 0; i < 10; i++)`

## While Loops

- Use a while loop when you don't know how many times when the loop will execute or the condition is external to the loop
